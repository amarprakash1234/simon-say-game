# 🎮 Simon Says Game

A fun and interactive memory game inspired by the classic Simon Says challenge. Players must remember and repeat an increasingly long sequence of colors to test their memory, focus, and concentration.

## ✨ Features

- 🎨 Interactive color-based gameplay
- 🧠 Memory and sequence-recall challenge
- 📈 Increasing difficulty as the game progresses
- 🏆 Score or level tracking
- 🔄 Restart and replay functionality
- 🖥️ Simple and user-friendly interface

## 🎯 How to Play

1. Start the game.
2. Watch the sequence of highlighted colors.
3. Repeat the sequence in the same order.
4. Each successful round adds another step to the sequence.
5. Continue as long as you can remember the complete sequence.
6. Restart the game and try to beat your previous score.
